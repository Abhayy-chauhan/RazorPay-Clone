# Razorpay Clone 🚀

A responsive clone of the **Razorpay** landing page built using **Vite**, **Tailwind CSS**, and modern web development best practices.

👉 **Live Demo:** [https://razor-pay-clone-seven.vercel.app/](https://razor-pay-clone-seven.vercel.app/)

---

## 📸 Overview

This project replicates the UI/UX design of Razorpay's home page, focusing on sleek animations, clean typography, dynamic layout structures, and pixel-perfect responsiveness across various screen sizes.

---

## ✨ Features

- **Modern Tech Stack:** Built with Vite for lightning-fast development and optimized production builds.
- **Tailwind CSS:** Fully styled using Tailwind utility classes for consistent and scalable UI design.
- **Responsive Layout:** Tailored for mobile, tablet, and desktop screens.
- **Pixel-Perfect UI:** Recreates complex hero sections, feature grids, cards, and CTA sections.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup structure
- **Tailwind CSS** – Styling and responsive layout design
- **Vite** – Frontend build tool and dev server
- **Vercel** – Hosting and continuous deployment
